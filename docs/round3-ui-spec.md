# Round 3 · 条目预览面板 V2 实现规格

> 面向 frontend / QA。设计唯一需求依据：`docs/round3-requirements.md`；组件级规格：`docs/ui-design.md` §2.12（V2）。
> 本文给的是**可直接照做的结构、尺寸、状态与断点**，不含 React 代码。所有尺寸单位 px，除注明外按 1x 屏幕。
> 静态视觉稿：`docs/round3-ui-mock.html`；截图：`docs/screenshots/round3-design-mock.png`（1440×900）、`docs/screenshots/round3-design-mock-1024.png`（1024×900）。图中封面为内联 SVG 示例，非真实条目图。
> 结论先行：**880px 右侧悬浮面板，上区左封面（固定槽 300×426 @1440）/右信息（506），下区简介（281）；封面 natural-size contain；面板高度只由视口决定，内容变化不改变面板几何。**

---

## 1. 硬约束（实现时不可破坏）

1. 面板 `position: fixed` + Portal 到 `body`，右缘对齐内容列右缘，**不随 hover 行上下移动**。
2. 面板宽度 `min(880px, 100vw - 176px)`：1440/1280 → 880，1024 → 848；**任何 ≥768 的视口都不横向溢出**。
3. 上区高度固定为 `Hc`，封面在固定槽内 `contain`；**加载中、失败、无封面、切换条目都不得改变面板高度或右栏位置**。
4. 封面：只用 `large`（原图）→ `common` → `small` → `grid` 回退；**不放大、不裁边、不 fetch/canvas**。
5. 右栏 `min-width: 0`，标题/标签/简介全部允许断行，**禁止横向滚动**。
6. 交互保持：150ms 开 / 120ms 关；面板内点击不跳转；滚轮只滚面板内部；`<768` 与触屏不启用。
7. 同一时刻只有一个面板；切换条目立即清除旧图与旧滚动位置，无残影。

## 4. 上区实现

### 4.1 DOM 顺序（无框架语义）

```
panel
├─ upper (height: --upper-h; display:flex; gap:--gap)
│  ├─ cover-slot (width:--cover-w; height:100%; flex:none; 居中)
│  │  ├─ img / placeholder / no-cover
│  ├─ info (flex:1; min-width:0; display:flex; flex-direction:column)
│  │  ├─ header (flex; gap:16; justify-content:space-between)
│  │  │  ├─ title-block (min-width:0; flex:1)
│  │  │  │  ├─ h3 原名（2 行）
│  │  │  │  └─ p 中文名（1 行）
│  │  │  └─ meta-block (flex:none; width:184; text-align:right)
│  │  │     ├─ row1 badge + date
│  │  │     ├─ row2 score
│  │  │     └─ row3 votes + rank
│  │  ├─ divider (mt14 / 1px / mb10)
│  │  └─ tags (flex:1; min-height:0; display:flex; flex-direction:column)
│  │     ├─ h4 标签 N（固定，不滚）
│  │     └─ chips-scroll (flex:1; overflow-y:auto; data-preview-scroll)
│  └─ ...
├─ divider (mt20 / 1px / mb16)
└─ summary (flex:1; min-height:0; display:flex; flex-direction:column)
   ├─ h4 简介（固定，18+8）
   └─ body-scroll (flex:1; overflow-y:auto; data-preview-scroll)
```

### 4.2 标题

- 原名 `name`：最多 2 行；`display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; overflow:hidden`；`overflow-wrap:anywhere`；`title` 放全名。
- 标题块**最小高度 2 行**（≥1280：50px），1 行标题也占满，防止切换时标签区上下跳。
- 中文名：仅 `nameCn && nameCn !== name` 时渲染；`truncate`；`title` 放全名；不预留空行。
- 不允许横向滚动；最长日文名必须在 2 行内截断。

### 4.3 元信息

≥1024（右对齐 184px 窄列）：

| 行 | 内容 | 缺失时 |
| --- | --- | --- |
| 1 | `[类型徽标] 2002-10-01` | 徽标「其他」；日期「日期未知」 |
| 2 | `8.7` + `分` | 「暂无评分」（13px `slate-400`，保留行高） |
| 3 | `1.2万人评分 · 排名 #1933` | 人数显示 `0 人评分`；rank 为 null/0 时省略 `· 排名 #…`；两者都缺失显示 `—` |

- 徽标颜色：漫画 emerald / 动画 sky / 音乐 violet / 游戏 amber / 三次元 rose（与列表一致）。
- 日期取 `formatYear(year, date)`；返回 `—` 时写「日期未知」。
- 人数用 `formatCount(scoreVotes)`。
- 三行高度固定（约 66px），切换有无评分/排名的条目时右栏不抖。

768–1023（元信息移到标题下方）：

```
[动画] 2002-10-01
8.7 分 · 1.2万人评分 · 排名 #1933
```

- `flex-wrap`；评分 16px；行距 4；整体不加固定宽，靠 `min-width:0` 防溢出。

### 4.4 标签

- 标题「标签 {tags.length}」；加载中「标签 …」。
- chips 容器：`display:flex; flex-wrap:wrap; gap:6px; align-content:flex-start; overflow-y:auto; overscroll-behavior:contain; scrollbar-width:thin; scrollbar-gutter:stable`。
- 每个 chip：
  - `inline-flex; align-items:baseline; gap:6px; max-width:100%; background:slate-100; border-radius:4px; padding:2px 8px; line-height:16px;`
  - 名称：`min-width:0; overflow:hidden; text-overflow:ellipsis; white-space:nowrap; max-width:100%;` + `title`。
  - 计数：`flex:none; font-variant-numeric:tabular-nums; color:slate-500; font-size:11px;`。
  - hover 背景 `slate-200`；**无 `cursor:pointer`、无 button 语义、无 onClick**。
- 最大高度：由右栏 flex 分配，不写固定 max-height。参考：1440×900 → 303；1280×900 → 303；1024×768 → 238；768×900 → 302。
- 溢出时只有 chips 容器滚动；标签标题固定。
- 公共标签：用户标签之后，`mt:8`；小标题 11px；chip 11px 描边；和用户标签共用一个滚动容器；为空则整段不渲染。
- 空态：「暂无标签」；错误态：「预览加载失败」（可带 12px「重试」文字按钮，非必需）。
- 骨架：5 个 `h-6 w-16` 圆角块，两行，`min-height:56px`，`aria-busy`。

## 5. 封面规则

### 5.1 槽与图片

- 槽：`--cover-w × --upper-h`，`display:flex; align-items:center; justify-content:center; overflow:hidden;`。
- 图片 CSS：
  ```
  max-width: 100%;
  max-height: 100%;
  width: auto;
  height: auto;
  object-fit: contain;
  border-radius: 6px;
  ```
- **不要**给 `img` 写 `width:100%` / `height:100%`（会放大）；不要用 `background-size:cover`（会裁切）；不要用 `fetch`/`canvas`（large 无 CORS）。
- 属性：`alt="{name} 封面"`、`loading="eager"`、`decoding="async"`、`referrerPolicy="no-referrer"`、`draggable="false"`。
- 居中留白是预期行为：超宽图上下留白、超窄图左右留白、小图周围留白；右栏几何不受影响。

### 5.2 1440×900 显示尺寸预期（槽 300×426）

| 原图 | 显示 | 规则 |
| --- | --- | --- |
| 600×900 | 284×426 | 高度受限 |
| 800×800 | 300×300 | 宽度受限 |
| 300×450 | 284×426 | 等比缩小 |
| 200×300 | 200×300 | 不放大 |
| 150×225 | 150×225 | 不放大 |
| 1200×300 | 300×75 | 超宽，留白 |
| 100×600 | 71×426 | 超窄，留白 |
| 400×400（旧缓存回退 common） | 300×300 | 回退图同样 contain |

### 5.3 占位

- 加载中：2:3 块，宽 `min(Wc, Hc*2/3)`、高 `min(Hc, Wc*3/2)`，居中；`slate-100` + pulse；`aria-busy="true"`；无文字。1440 下即 284×426。
- 无封面 / 全部 URL 失败：同一 2:3 块，静态 `slate-100`，居中「无封面」12px `slate-500`。
- 图片换源/切换条目时：占位块始终在图片下层；图片 `opacity:0`，`onLoad` 后 120ms 淡入；`prefers-reduced-motion` 时 0ms。

### 5.4 回退状态机

```
candidates = unique([large, common, small, grid].filter(Boolean))
current = 0
onError -> current += 1
  current < candidates.length -> 换 src，保持占位
  current >= candidates.length -> 无封面占位（不出现破图）
```

- `large === null`（旧缓存无法推导）直接使用 candidates 中的 common；若推导出的 large 实际 404，`onError` 继续回退即可，无需特殊分支。
- 数据语义：`covers[id] === undefined` = 该块尚未加载（可触发单 id 查询）；`null` = 已确认无封面/失败（直接占位，不重试）。
- 每条目的失败索引随条目重置；同一 URL 不会在同一面板会话内重复请求。
- 不要求用户清 `.cache/covers.db`；服务端已做 v5 列迁移与推导。

## 6. 下区简介

- 分隔线横贯面板内宽（左右都到内边距）。
- 标题「简介」12/18 600 `slate-700`，下边距 8，**不滚动**。
- 正文：`flex:1; min-height:0; overflow-y:auto; overscroll-behavior:contain; scrollbar-width:thin; scrollbar-gutter:stable;`；13/1.7 `slate-600`；`white-space:pre-wrap; overflow-wrap:anywhere;`。
- 不折叠、不截断、不加「展开」按钮；内容不足时自然留白（容器高度仍占满）。
- 加载：3 行骨架（总高约 72）+「正在加载简介…」12px `slate-400`；空：「暂无简介」12px `slate-400`。
- 简介接口不会抛错；若上游失败统一按「暂无简介」显示，不设红色错误条。
- 1440×900 可视 281px（≈12 行）；1024×900 289；1024×768 225；768×900 297。

**切换条目防残影（必须逐条做到）**

1. 组件实例可复用，但封面状态以 `subject.id` 为界：id 变化时**同步**把封面状态重置为「加载中」，并用 `key` 让旧 `<img>` 立即卸载。
2. 新图片 `opacity:0` 直到 `onLoad`；`onLoad` 回调校验当前 id/URL，迟到回调不得点亮新条目。
3. 失败索引、已加载 URL、旧滚动位置（简介 + 标签）全部重置；`scrollTop=0` 在 DOM 更新后执行。
4. 标签/简介查询键含 id，不使用 `keepPreviousData`；旧数据不得在新 id 下短暂显示。
5. 面板位置不依赖行 `rect`，切换行不会移动面板。

## 9. 与现有实现的衔接 / 待 Lead 确认

### 9.1 现状核对（截至设计时）

| 项 | 现状 | 对设计的影响 |
| --- | --- | --- |
| `CoverUrls.large` | 后端已加 `large`（`string` 或 `null`），缓存 v5 仅加列、旧行可推导 | 前端按 `large → common → small → grid` 回退即可 |
| `HoverPreview` 入参 | 目前只有 `id/name/type/year/date` | V2 需补 `nameCn/score/scoreVotes/rank` 与 `cover`；`ResultList` 的 `hoveredSubject` 已是完整 `SubjectCardDto` |
| 封面来源 | 目前预览不显示封面 | 优先复用 `covers[id]`；若该块尚未加载，按单 id 触发一次 `subject.covers`（可接受多一次已缓存查询） |
| 面板几何 | 现有 `PANEL_MAX_WIDTH=640`、`48vw` | 必须替换为 §3 公式；旧的 640/48vw 全部废弃 |
| 标签区 | 现有 `max-h-[200px]` + 独立公共标签区 | 合并为一个 flex 剩余高度滚动容器；公共标签置于其后 |
| 简介错误 | `subject.summary` 永不抛错 | 保持「暂无简介」，不加错误态 |
| 旧缓存 | `large` 推导依赖 `/r/<n>/` 前缀 | QA 需用旧缓存实测；推导失败会回退 common（非原图），列入风险 |
| 列表遮挡 | 面板会盖住列表右半 | 本轮不做「列表右移」，沿用已确认取舍 |

### 9.2 需要 Lead 确认的假设

- **A1（最重要）**：需求原文说「上区高度由封面决定」，但图片自然比例在加载前不可知；为满足「加载不得布局跳动」，本设计把上区高度固定为 `Hc`，封面在槽内 contain。若坚持动态上区高度，则必须接受加载/切换时的面板高度变化。
- **A2**：1024 宽面板取 **848**（`vw-176`），不是 880，以保住 152px 的左侧悬浮通道；1280 及以上仍为 880。若确认 1024 也要 880，可改为 `min(880, vw-48)`：面板左缘 120、可悬浮通道 104，右栏变为 530，其余尺寸不变。
- **A3**：768–1023 启用预览（需求只要求 <768 关闭），采用更窄封面列 + 元信息移到标题下方的紧凑布局。
- **A4**：元信息只展示「类型 / 日期 / 评分 / 人数 / 排名」，不展示 `看过`（favoriteDone）；如需展示，放第 3 行末尾，仍可容纳。
- **A5**：封面允许「复用列表 cover map + 缺失时单 id 查询」，不新增服务端接口。
