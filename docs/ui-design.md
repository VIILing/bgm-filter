## 2. 组件规格

### 2.1 `Header`
- 深色 `bg-slate-900 text-slate-100`，高约 56px。
- 左侧标题「BGM Filter」+ 小字副标「Bangumi 条目筛选器」。
- 右侧统计（来自 `stats`）：`共 {total} 条 · 有标签 {taggedTotal} 条`；加载中显示 `…`，失败不阻塞页面。

### 2.2 `TagExprInput`（核心）
- 单行 input，`font-mono`，placeholder：`科幻 & (恋爱 | 百合) & !R18`。
- 实时解析（前端本地调用同一份 parser？——V1 允许前端仅做**轻量**校验或直接展示服务端返回；若前端不便复用，采用「输入后 300ms 由服务端 search 返回错误」的方式，但**解析状态区**必须在无请求时也能提示明显错误，如未闭合引号/括号的本地启发式）。**决策**：parser 用同构 TS 实现，放 `src/lib/tag-parse-lite.ts`，前端只做语法校验与标签名提取，不做求值；服务端 `src/server/tag-dsl/parser.ts` 为权威实现。两份需同构，单测各自覆盖。
- 状态行：
  - 合法：`text-emerald-600`，`✅ 表达式合法 · 涉及 N 个标签`。
  - 非法：`text-red-600`，`⛔ {message}（第 {position+1} 个字符附近）`，输入框 `ring-red-300`；**不打断输入、不发请求**。
  - 空表达式：`text-slate-500`，`未限制标签`。
- 候选下拉：输入 ≥1 字符且光标处于某个裸标签片段内时，调用 `subject.tags({q, limit:20})`，debounce 200ms；展示 `名称 · 12,345 条`；键盘 ↑↓ 选择、Enter 插入、Esc 关闭；点击插入。
- 常用标签 chips：`subject.tags({q:"", limit:12})`，点击追加。
- **插入规则**（`insertTag(expr, cursor, tag)` 纯函数，需单测）：
  - 若光标前一个非空白字符不是运算符/左括号且表达式非空 → 自动补 ` & `；
  - 标签名含空白或 `& | ( ) ! ~ "` → 包成 `"..."`，内部 `\` → `\\`、`"` → `\"`；
  - 若该标签已在表达式中（按 lower 比较）→ 不重复追加，仅聚焦；
  - 插入后光标落在新标签之后。

### 2.3 `YearRangeInput`
- 两个 `type="text" inputMode="numeric"`；placeholder `不限`。
- 非法（非整数、越界 1000–2100）：红字「年份需为 1000–2100 的整数」。
- `from > to`：红字「起始年不能大于结束年」，且**不发起查询**（保留上一次结果）。

### 2.4 `TypeFilter`
- 5 个 checkbox（漫画/动画/音乐/游戏/三次元），标签后显示计数，如 `动画 31,258`。
- 全不选 = 全选（URL 中写 `types=`? 不——按契约 undefined/[] 视为全选，URL 省略 types 表示全选；用户手动全取消时 URL 省略 types，UI 表现上恢复全选勾选，避免「取消后变全选」的认知冲突。**决策**：全取消时 UI 自动回填全选并提示一次「已恢复为全部类型」）。

### 2.5 `SortControls`
- 排序：三个分段按钮「综合评分」（默认）、「评分从高到低」、「评分从低到高」；「综合评分」旁 `?` 提示「按贝叶斯加权：评分 × 人数，弱化 1 人打 10 分的刷分效应」。
- 无评分：分段按钮「置底」「置顶」，旁边 `?` 提示「仅影响无评分条目，同组内按 ID 升序」。

### 2.6 `ResultSummary`
- `共 {total.toLocaleString()} 条 · 第 {page}/{totalPages} 页`；查询耗时 right-aligned 小字（可选）。
- `warnings` 逐条黄色提示：`⚠ 未知标签：foo`。
- 有标签条件时显示「清空标签」按钮。

### 2.7 `SubjectCard`（行式卡片）
- 左侧封面块：`aspect-[2/3]`，桌面宽 76px、移动宽 56px，`overflow-hidden rounded bg-slate-100`；`<img src={cover.small}>`（`lain.bgm.tv/r/200`）带 `loading="lazy"` `decoding="async"` `referrerPolicy="no-referrer"`；无封面 / 加载失败 → 居中「无封面」灰块（保持 2:3，不产生 CLS）；NSFW 条目同样正常显示封面。
- 主区：
  - 第一行：`name`（`text-base font-medium truncate`，`title` 全文），右侧类型徽标（漫画=emerald、动画=sky、音乐=violet、游戏=amber、三次元=rose，浅底深字）+ 日期/年份。
  - 第二行：`nameCn`（若存在且 ≠ name，`text-sm text-slate-500 truncate`）+ 评分 `8.7 · 1.2万 人评分`（`font-medium tabular-nums`；无评分显示 `— 无评分`）+ `#rank` + `看过 {n}`。
  - 第三行：标签 chips（最多 8，`text-xs`，`bg-slate-100`，hover 变 `bg-slate-200`），点击追加表达式。
- 整卡 `<a href="https://bgm.tv/subject/{id}" target="_blank" rel="noreferrer">`；标签 chip 点击 `preventDefault` + `stopPropagation`。
- hover：`bg-slate-50`；窄屏（<640px）评分块移到顶部一行，卡片纵向排列。

### 2.8 `SkeletonRows`
- 50 行占位（可只渲染 10 行视觉重复），`animate-pulse`，高度与真实行一致（约 96px），避免跳动。

### 2.9 `EmptyState`
- 图标 + 「没有匹配的条目」+ 当前条件摘要（标签/年代/类型/搜索词）+ 三个按钮：`清空标签`、`放宽年代`、`取消名称搜索`（按当前生效条件显示）。

### 2.10 `ErrorState`
- 红色警示框 + 「加载失败：{message}」+ 若 message 含 database/表不存在 → 追加「数据库未导入？请先在终端运行 `pnpm db:import`」。
- 重试按钮。

### 2.11 `Pagination`
- 按钮：首页 «、上一页 ‹、页码窗口（当前 ±2，首尾固定显示，间隔用 `…`）、下一页 ›、末页 »。
- 当前页 `aria-current="page"`；禁用态 `opacity-40 cursor-not-allowed`。
- 页码点击 → 只改 `page`，滚动到结果区顶部（`scrollIntoView({behavior:"smooth"})`）。

#### 2.12.1 形态、定位与精确尺寸

面板仍是 **Portal 到 `document.body` 的 `position: fixed`**，白底、`rounded-xl`、`border border-slate-200`、`shadow-xl`、`z-50`、`overflow-hidden`；**固定右侧、不随行上下移动**。行 hover 只切换内容。

| 参数 | 规则 | 1440×900 | 1280×900 | 1024×900 / 1024×768 |
| --- | --- | --- | --- | --- |
| 面板宽 `W` | `min(880px, vw - 176px)` | 880 | 880 | 848 |
| 右缘 `right` | `max(16, (vw - min(vw - 32, 1280)) / 2 + 8)` | 88 | 24 | 24 |
| 左边 `left` | `vw - right - W` | 472 | 376 | 152 |
| 顶 `top` | `64`（Header 56 + 8） | 64 | 64 | 64 |
| 高 `H` | `min(max(vh - 80, 420), vh - 72)` | 820 | 820 | 820 / 688 |
| 内边距 `P` | 24 / 20 / 16（按断点） | 24 | 24 | 20 |
| 封面列 `Wc` | 300 / 288 / `clamp(208, 28%, 240)` | 300 | 300 | 288 |
| 列间距 `G` | 24 / 20 / 16 | 24 | 24 | 20 |
| 上区高 `Hc` | `clamp(280, 0.52 × H, 440)` | 426 | 426 | 426 / 358 |
| 右栏实际宽 | `W - 2P - Wc - G - 2`（含 1px 边框） | 506 | 506 | 498 |
| 右栏最小宽 | 478 / 458 / 334 | 478 | 478 | 458 |
| 简介可视高 | 剩余高度（约） | 281 | 281 | 289 / 225 |

- **宽度公式的取舍**：`vw - 176` 保证窄视口下左侧始终留出约 **152px 的悬浮通道**（内容区最左 136px 可见），否则 1024 宽下 880px 面板只剩 120px 可悬浮区域。≥1056px 后宽度封顶 880。
- 面板高度距离视口底部 16px；底部不留贴边。
- 上区与下区之间：分隔线 `1px`，上边距 20、下边距 16（合计 37）。
- 所有宽度用 `border-box`；右栏 `min-width: 0`，禁止横向溢出。
- **Round 4 复用说明**：V3 只沿用本表的面板宽高、内边距、封面列、间距、上区高与右栏宽度；`top`、`right`、`left` 三行仅 V2 存档，弹窗定位改为视口居中（§2.13.2）。

#### 2.12.2 上区结构（左封面 + 右信息）

```
右栏 = 标题块 + 元信息块（≥1024 并排；768–1023 元信息换到标题下方）
      ─ 分隔线 ─
      标签区（标题 + 可滚动 chips）
```

**封面槽**
- 尺寸固定为 `Wc × Hc`，图片在槽内水平+垂直居中；**槽的尺寸与图片是否加载无关**，这是面板不跳动的前提。
- 图片规则见 §2.12.3；圆角 6px，只作用于图片本身。

**标题（日文原名）**
- 文案：`name`（Bangumi 原名；没有单独中文名时它就是主标题）。
- 字号/行高：18px / 1.4（1024–1279 为 17px，768–1023 为 16px）；字重 600；颜色 `slate-900`。
- **最多 2 行**，`-webkit-line-clamp:2` + `overflow-wrap:anywhere`；完整名称放 `title` 属性。
- 标题块**预留 2 行高度**（≥1280 约 50px），标题只有 1 行时下方留白，避免切换条目时标签区上下跳。

**中文名**
- 文案：`nameCn`，仅当非空且 ≠ `name` 时显示；13px / 1.5，`slate-500`，**单行截断**，完整值放 `title`。
- 不预留空行：无中文名时标签区上移约 22px（属内容差异，不视为错位）。

**元信息块**
- ≥1024：右对齐窄列，固定宽 **184px**，与标题块顶部对齐，三行、固定高度约 66px：
  1. 类型徽标 + 日期：`[动画] 2002-10-01`。徽标 11px，颜色沿用列表（漫画 emerald / 动画 sky / 音乐 violet / 游戏 amber / 三次元 rose）；日期 12px `tabular-nums`，无日期显示「日期未知」。
  2. 评分：`8.7` 20px / 600 `tabular-nums` + `分` 11px `slate-500`；无评分显示「暂无评分」13px `slate-400`（保留行高）。
  3. 评分人数与排名：`1.2万人评分`（`formatCount`）+ `排名 #1933`（rank>0 才显示），11px `slate-500`；都缺失时显示 `—`。
- 768–1023：元信息块移到标题块下方，左对齐、允许换行（`flex-wrap`，行距 4px）；评分降为 16px。**右栏本身不换到封面下方**，始终在封面右侧。
- 文案统一：`排名 #1933`（不写 `rank`）、`1.2万人评分`（不写「人评价」）。

**分隔线**
- 右栏内 1px `slate-100`，上边距 14、下边距 10。

**标签区**
- 标题：`标签 {n}`，12px / 600 `slate-700`；`n` 用 `tabular-nums` `slate-500`；加载中显示 `标签 …`。
- chip：`名称 + 计数`，一行内两端对齐；名称 12px `slate-700`，计数 11px `slate-500` `tabular-nums`；底色 `slate-100`、圆角 4px、内边距 `2px 8px`、chip 间距 6px；长名称 `max-width:100%` + 截断 + `title`；hover 底色 `slate-200` 但**不可点击、无指针手型**。
- 最大高度：由右栏剩余空间决定（`flex:1; min-height:0`），不设固定像素上限。1440×900 下约 **303px**（≥10 行 chip）；1024×768 下约 238px；768×900 下约 302px。
- 滚动：chips 容器 `overflow-y:auto; overscroll-behavior:contain; scrollbar-width:thin`，**只有这一块滚动**；标题固定不滚。
- 公共标签：接在用户标签之后、同一个滚动容器内；小标题「公共标签」11px `slate-400`，chip 为 11px 描边样式（`border-slate-200 text-slate-500`）；没有则整段省略。
- 空态：「暂无标签」12px `slate-400`；加载骨架为 2 行、约 56px 高的灰色 chip，保证高度不塌。

#### 2.12.3 「自然尺寸、不放大、不裁边」规则

- 只使用 `large`（原图，无 `/r/` 前缀）URL，普通 `<img>` 直连 `lain.bgm.tv`；**禁止 fetch / canvas / background-image 读像素**（large 无 CORS，`<img>` 不受影响）。
- 封面槽固定 `Wc × Hc`；图片 `max-width:100%; max-height:100%; width:auto; height:auto; object-fit:contain`，居中。
- 判定：
  1. 原图两边都小于槽 → **按自然尺寸显示**（例如 150×225 就是 150×225），不放大、不居中拉伸。
  2. 原图任一边大于槽 → 以 `min(Wc/原宽, Hc/原高)` **整体等比缩小**，不裁切。
  3. 极端比例（超窄/超宽）只会在槽内留白，**右栏宽度与位置不变**，因为封面列宽是固定的。
- 1440×900（槽 300×426）实测预期：

| 原图尺寸 | 显示尺寸 | 说明 |
| --- | --- | --- |
| 600×900（2:3） | 284×426 | 高度受限，完整显示 |
| 800×800 | 300×300 | 宽度受限 |
| 300×450 | 284×426 | 略缩，不裁边 |
| 200×300 | 200×300 | 小图不放大 |
| 150×225 | 150×225 | 小图不放大 |
| 1200×300 | 300×75 | 超宽，留白 |
| 100×600 | 71×426 | 超窄，留白 |

- 图片属性：`alt="{name} 封面"`、`loading="eager"`、`decoding="async"`、`referrerPolicy="no-referrer"`、`draggable="false"`。
- `large` 为 `null`（旧缓存无法推导）时直接用 `common`；`large` 加载失败依次回退 `common → small → grid`，全部失败显示「无封面」占位。

**占位尺寸（防跳动）**
- 封面加载中：封面槽内放一个 **2:3 占位块**，宽 `min(Wc, Hc × 2/3)`、高 `min(Hc, Wc × 3/2)`，居中；`slate-100` + `animate-pulse`，不加文字，`aria-busy="true"`。
- 无封面 / 全部回退失败：同一个 2:3 占位块，静态 `slate-100`，居中「无封面」12px `slate-500`；**绝不出现破图图标**。
- 占位块有固定尺寸，封面到达后只替换块内内容，**面板高度、右栏位置不变**。

#### 2.12.4 下区简介

- 分隔线横贯整个面板（不是只到右栏）；「简介」小标题 12px / 600 `slate-700`，下边距 8。
- 简介正文：13px / 1.7（约 22px 行高）、`slate-600`、`white-space:pre-wrap`、`overflow-wrap:anywhere`；**不折叠、不 line-clamp**，占满剩余高度，内部滚动（`overscroll-behavior:contain; scrollbar-width:thin`）。
- 剩余高度：1440×900 约 281px（≈12 行）；1024×900 约 289px；1024×768 约 225px；768×900 约 297px。
- 空简介：「暂无简介」12px `slate-400`；加载中：「正在加载简介…」+ 3 行灰色骨架（固定约 72px），不撑高面板。
- 简介接口永不抛错（404/网络/熔断/空统一返回 `null`），因此不设错误态。

#### 2.12.5 四态与降级

| 状态 | 表现 | 面板布局 |
| --- | --- | --- |

#### 2.12.7 交互与可访问性（V2 存档；Round 4 已由 §2.13 取代）

> 以下 150/120ms 触发、hover 关闭、页面滚动关闭等规则已停用；仅保留滚轮「内部滚动」与封面 120ms 淡入两条视觉细节，详见 §2.13。

- **触发**：`mouseenter` 行 150ms 后打开；`mouseleave` 行 120ms 后关闭；指针进入面板取消关闭，离开面板重新计时。面板出现/消失**不加位移动画**（避免指针误入），仅封面加载完成做 120ms 淡入。
- **点击**：面板整体 `stopPropagation`；面板内没有链接；标签 chip 不可点击；点击列表行其它区域仍跳 bgm.tv。
- **滚轮**：面板根节点 native `wheel` 监听 + `passive:false`，`preventDefault()` 后只滚动最近的 `[data-preview-scroll]` 容器（简介 / 标签 chips）；到边界或指针不在滚动区时**吞掉滚轮，绝不带动页面/列表**；`deltaMode` 为行/页时换算。
- **关闭**：页面滚动 / 窗口 resize 关闭（面板内部滚动不算）；筛选或翻页换结果时立即关闭。
- **不启用**：`<768px` 或 `(hover: none)`。
- **可访问性**：`role="tooltip"`、`aria-label="条目预览：{name}"`；封面 `alt`；加载区 `aria-busy`；装饰骨架 `aria-hidden`；简介与标签滚动容器 `tabIndex=0` + `aria-label`（简介/标签）+ 可见焦点环，保证键盘可滚动；标签 chip 无 `button` 语义；颜色对比：正文 `slate-600`、计数 `slate-500` 均 ≥4.5:1，占位文字 `slate-500`；`prefers-reduced-motion` 下关闭 pulse 与淡入。

#### 2.12.8 数据与契约依赖（供 backend/frontend 对照）

- 封面：`subject.covers` 的 `CoverUrls` 必须含 `large: string | null`（原图）；旧缓存由服务端无损升级/推导，前端只做回退。

#### 2.13.3 遮罩与层级

- 遮罩：`position: fixed; inset: 0; background: rgba(15,23,42,0.22);`（`slate-900` 22%），叠加 `backdrop-filter: blur(2px)`；不支持模糊时退化为纯半透明。整体呈**淡灰**，不是黑色。
- 遮罩覆盖整个视口，**含 Header 与筛选区**；Header 不再可点。
- 层级：页面/Header（Header z-30）< 遮罩 `z-100` < 面板 `z-101` < 独立按钮 `z-102` = 底部提示 `z-102`。按钮必须高于遮罩；提示 `pointer-events:none`。
- 面板阴影落在遮罩之上；遮罩自身不可滚动。
- 遮罩空白处左键关闭（**已确认启用**）；点击面板/按钮不关闭。为避免拖选文字误关，只有 `pointerdown` 与 `click` 都发生在遮罩本身时才关闭。

#### 2.13.4 独立「跳转至 BGM」按钮

- 不属于预览面板布局；`position: fixed`，**顶边与面板顶边平齐**，位于面板右缘外 20px（≥1280）/16px（768–1279）。
- **统一 56×56 紧凑款**：纵向排列 external-link 图标 18 + 「BGM」10px/500；圆角 14；`aria-label` 与 `title` 为「跳转至 BGM（在新标签页打开）」。
- 视觉：深色实心 `bg-slate-900`、白字、`shadow-lg`；hover `bg-slate-800`，active `bg-slate-950`；focus-visible 2px `sky-400` 外环、offset 2。
- 行为：点击 `target="_blank"` 打开 `https://bgm.tv/subject/{id}`，`rel="noreferrer"`；**弹窗保持打开**，不改变面板内部状态；点击事件 `stopPropagation`，不触发遮罩关闭。
- 不设 disabled：即使预览数据/封面失败，按钮仍可用（跳转不依赖预览接口）。
- 1024/768 下按钮与面板不重叠、不溢出；1440 下右侧余 204，属用户确认的「按钮变小后右侧较空」。
#### 2.13.5 关闭方式与提示

| 方式 | 是否启用 | 规则 |
| --- | --- | --- |

- 关闭时禁止再次点击遮罩/按钮；动画结束后卸载。

#### 2.13.6 动画、滚动锁定与焦点

- **打开（主视觉约 220ms；按钮延迟后最晚约 250ms）**：
  - 遮罩 `opacity 0→1`，**180ms ease-out**；
  - 面板 `opacity 0→1`，**160ms ease-out**；`transform: scale(0.92) translateY(6px) → scale(1) translateY(0)`，**220ms**，缓动 `cubic-bezier(0.34, 1.56, 0.64, 1)`（轻微回弹：约 120ms 峰值 scale≈1.008，随后回落）；
  - 右侧 56×56 BGM 按钮跟随弹入：`opacity` + `translateY(6px→0)`，**220ms**，同缓动，**延迟 24ms**（20–30ms 区间）；按钮约 244ms 完成；
  - 只动 `transform` / `opacity`，不改变面板宽高、列宽或布局；回弹幅度约 0.8%，不会造成横向溢出；
  - 居中与动画必须分离：外层负责 `translate(-50%,-50%)` 居中，内层做 scale/translateY（或使用独立的 `translate`/`scale` 属性），禁止用动画 transform 覆盖居中 transform。
- **关闭**：约 **140ms ease-in**；遮罩/面板/按钮 `opacity→0`，面板 `scale→0.97`；无回弹、无位移；动画结束后卸载、解除滚动锁定、焦点返回触发行。
- **reduced-motion**：`prefers-reduced-motion: reduce` 时移除缩放、位移、回弹和延迟；opacity 用 0–1ms 直接切换（总时长 ≤1ms）；滚动锁定与焦点仍即时生效。
- 打开过程中允许右键 / Esc / 点遮罩关闭；若在打开中关闭，从当前视觉状态走 140ms 关闭，不等待回弹结束。
- **滚动锁定**：打开时 `html/body overflow:hidden`，用 `scrollbar-width` 补偿 `body padding-right`，避免页面横移；关闭后恢复原滚动位置与样式。遮罩 `overscroll-behavior: none`。
- **面板内部**：简介/标签仍各自内部滚动；滚轮在面板内不带动页面（页面已锁定），到边界被吞掉。`data-preview-scroll` 机制沿用 V2。V2 的「页面滚动关闭」不再需要。
- **焦点**：打开时记住触发元素 → 焦点移到 dialog 容器（`tabindex=-1`，无可见 outline）→ 背景容器 `inert`（或等效焦点隔离）→ Tab 在「标签滚动区 → 简介滚动区 → BGM 按钮」间循环 → 关闭后焦点回触发元素。焦点环仅出现在滚动区/按钮上。
- 弹窗期间背景不可交互（遮罩 + inert），Header/筛选/列表/分页均不可聚焦、不可点。

## 4. 状态与数据流

```
URL query ──parseFilterState──▶ FilterState ──(debounce 300ms)──▶ trpc.subject.search.useQuery
     ▲                                   │
     └──────── toSearchParams ◀──────────┘（page 变更立即写，不 debounce）
```
- 筛选条件变化：`page` 重置为 1，debounce 300ms 后 `router.replace(url, {scroll:false})`。
- 分页变化：立即写 URL。
- `useSearchParams` 必须在 `<Suspense>` 内；首屏用 URL 初始值渲染，避免闪烁。
- `keepPreviousData: true`，切换条件时保留旧列表 + 顶部细进度条（`isFetching`）。
