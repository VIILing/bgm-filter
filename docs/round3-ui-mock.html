简介

2029 年，电子脑与义体化已成为常态。人类的意识可以被数字化，也可以被入侵、篡改与复制。公安九课是一支专门处理网络犯罪与恐怖袭击的独立部队，由草薙素子少佐率领。

在追查一起政客绑架案时，素子与队友发现幕后黑手并非普通的恐怖组织，而是一个能够入侵人类电子脑、改写记忆的「笑面男」。随着调查深入，他们逐渐触及国家权力、企业利益与个体自由之间的灰色地带。

本作以单元剧的形式展开，每一集都从一个具体的案件切入，讨论义体化社会中的身份认同、记忆的真实性、以及信息网络对政治的侵蚀。草薙素子与巴特、陀古萨、石川等队员之间的配合，构成了整部作品最稳定的情感支点。

与剧场版相比，TV 系列更注重群像与制度描写：公安九课并非无所不能，他们同样受制于官僚体系与舆论压力。正是在这种限制之下，队员们仍然选择追查真相，构成了作品最核心的英雄主义。

音乐由菅野よう子负责，开场曲《Inner Universe》与多首插入曲成为动画音乐史上的经典。冷峻的赛博朋克都市、密集的对话、克制的动作场面，共同塑造了 2000 年代科幻动画的标杆。
