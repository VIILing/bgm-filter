# Round 4 · 条目点击弹窗（V3）实现规格

> 面向 frontend / QA / 用户确认。依据：`docs/round4-requirements.md`、`docs/ui-design.md` §2.13（V3）、§2.12（面板内部布局，保持不变）。
> 本文不含 React 代码；尺寸单位 px（1x），bbox 均为 `getBoundingClientRect` 预期值。
> 静态视觉稿：`docs/round4-ui-mock.html`；截图：`docs/screenshots/round4-design-1440.png`、`round4-design-1024.png`、`round4-design-768.png`。封面为内联 SVG 示例。mock 已带打开弹性 pop（无关闭交互）；截图为动效终态。

---

## 1. 不可破坏的约束

1. **面板内部布局完全沿用 Round 3 V2**：不改列宽、字号、信息项、封面规则、简介/标签滚动；只改变面板的定位方式。
2. 点击条目打开**唯一**弹窗；不再有 hover 预览、hover 请求、原图预取。
3. 面板在视口中**水平、垂直居中**，不是「Header 下方」；接受压住 Header 底部约 16px（已确认）。
4. 独立 BGM 按钮**统一 56×56**，在面板右缘外，**顶边与面板顶边平齐**（不再垂直居中）；**不能为了按钮压缩面板**。
5. 弹窗期间遮罩覆盖全视口（含 Header），背景不可交互、不可滚动。
6. 右键任意位置关闭且阻止浏览器菜单；Esc 与左键点遮罩空白也关闭；面板/按钮左键不关闭；按钮点击不关闭弹窗。
7. `<768` **或触屏**不启用弹窗（已确认）；点击仍直接打开 bgm.tv。

## 3. 精确几何

### 3.1 面板

沿用 V2：

```
W = min(880, vw - 176)
H = min(max(vh - 80, 420), vh - 72)
left = (vw - W) / 2
top  = (vh - H) / 2
```

| 视口 | 面板 bbox | 面板右缘 | 垂直 |
| --- | --- | --- | --- |
| 1440×900 | 880×820 @ (280,40) | 1160 | 上下各 40 |
| 1280×900 | 880×820 @ (200,40) | 1080 | 上下各 40 |
| 1024×900 | 848×820 @ (88,40) | 936 | 上下各 40 |
| 768×900 | 592×820 @ (88,40) | 680 | 上下各 40 |

- 内部参数不变：1440 内边距 24、封面槽 300×426、右栏 506；1024 内边距 20、封面槽 288×426、右栏 498；768 内边距 16、封面槽 208×426、右栏 334。
- **Header 重叠**：900 高时 top=40，Panel 会盖住 Header 底部 16px（遮罩仍压暗 Header）。这是严格视口垂直居中的结果；若要求完全避开 Header，只能改为 top=56（面板中心下移 16，不再严格居中，见 §11 #9）。
- 768 下标题/元信息仍按 V2 的紧凑布局（元信息在标题下方），**不改内部**。

### 3.2 独立按钮

| 视口 | 尺寸 | bbox | 间距 | 右缘距视口 | 顶边 |
| --- | --- | --- | --- | --- | --- |
| 1440×900 | 56×56 | (1180,40) | 20 | 204 | 与面板顶边平齐 |
| 1280×900 | 56×56 | (1100,40) | 20 | 124 | 与面板顶边平齐 |
| 1024×900 | 56×56 | (952,40) | 16 | 16 | 与面板顶边平齐 |
| 768×900 | 56×56 | (696,40) | 16 | 16 | 与面板顶边平齐 |

- 全部宽度使用同一款 56×56；没有宽屏文字款。
- 定位公式：`left = (vw + W)/2 + G`；`top = panel.top`；`G` 在 ≥1280 为 20、768–1279 为 16。
- 1024/768 的 88px 右侧空间 = 16 间距 + 56 按钮 + 16 边距，**恰好放下**；不压缩面板内部。
- 1440 下右侧余 204：按钮变小后右侧较空，是用户明确接受的取舍。
- 不做「面板 + 按钮整体居中」的 wrapper——那会把面板推离视口中心。按钮必须相对**已居中的面板**定位。
- 按钮不参与面板的宽度计算，不影响任何内部列宽。

### 3.3 顶边与底部提示

- 按钮**顶边**与面板顶边平齐：900 高时 top=40，按钮 y=40–96；不再按面板中线对齐。
- 底部提示：`bottom:8px`，水平居中，11px，高度约 22–24px；面板底缘 860，提示不与面板重叠。
- 1024/768 高度 900 时同样 top=40；视口更矮时面板 H 随公式收缩，按钮仍跟随面板顶边，提示固定在底部。

## 4. 遮罩与层级

| 项 | 规格 |
| --- | --- |
| 颜色 | `#0F172A` 22%，即 `rgba(15,23,42,0.22)`；对白色页面呈淡灰（约 `#C6CBD4`） |
| 模糊 | `backdrop-filter: blur(2px)`；不支持时纯色退化，不降级为黑色 |
| 覆盖 | `position:fixed; inset:0`；含 Header、筛选、列表、分页 |
| 滚动 | 遮罩本身不滚；页面锁定 |
| 左键空白 | 关闭（已确认）；只在遮罩本身按下+抬起时触发 |
| 右键 | 任意位置关闭，阻止浏览器菜单 |
| 交互 | 遮罩挡住背景；背景不可点、不可聚焦 |

**z 轴顺序**

| 层 | z-index | 说明 |
| --- | --- | --- |
| Header | 30 | 被遮罩压暗，不可交互 |
| 页面/筛选/列表 | 0–20 | 被遮罩覆盖 |
| 遮罩 | 100 | 全屏 |
| 预览面板 | 101 | 白底、圆角 12、阴影，必须高于遮罩 |
| 独立 BGM 按钮 | 102 | 必须可点，不被遮罩盖住 |
| 底部提示 | 102（`pointer-events:none`） | 不挡点击 |

- 面板阴影 `0 25px 50px -12px rgba(15,23,42,0.28)`；遮罩不会盖住面板。
- 弹窗打开时 Header 的 sticky 行为不参与；背景整体 inert。

## 9. 动画、滚动锁定、焦点

### 9.1 动画（打开约 220ms，关闭 140ms）

**打开参数**

| 元素 | 属性 | 时长 | 缓动 | 延迟 |
| --- | --- | --- | --- | --- |
| 遮罩 | `opacity 0→1` | 180ms | `ease-out` | 0 |
| 面板 | `opacity 0→1` | 160ms | `ease-out` | 0 |
| 面板 | `scale(0.92)→scale(1)` + `translateY(6px)→translateY(0)` | 220ms | `cubic-bezier(0.34,1.56,0.64,1)` | 0 |
| BGM 按钮 | `opacity 0→1` + `translateY(6px)→translateY(0)` | 220ms | 同面板 | 24ms（20–30ms 区间） |

- 面板主视觉 220ms 完成；按钮因 24ms 延迟约 244ms 完成。用户要求的「总时长约 220ms」指主面板；按钮最晚不超过约 250ms。
- 面板 transform 的轻微回弹峰值约 `scale=1.008`（约 120ms），随后回落至 1；回弹不超过面板四周视口余量（768 下左右各 88px，0.8% 约 2.4px），不产生横向滚动。
- 按钮属于 dialog 层，随面板一起出现（延迟 24ms）；不得等面板完全结束后再出现。
- 居中 transform 与动画 transform 必须分离：外层负责 `translate(-50%,-50%)`，内层负责 scale/translateY；或使用独立的 `translate` / `scale` 属性。禁止用动画 transform 覆盖居中 transform，否则面板会跳到左上角。

**transform 采样（QA 用，理论值；允许 ±0.01 scale / ±1px）**

| 时间 | panel scale | panel translateY | 说明 |
| --- | --- | --- | --- |
| 0ms | 0.920 | +6.00px | 初始，opacity 0 |
| 80ms | 0.9995（≈1.000） | +0.04px（≈0） | 快速接近终值 |
| 120ms | 1.0077 | −0.58px | 回弹峰值（可选采样点） |
| 160ms | 1.0054 | −0.40px | 面板 opacity 应已达 1 |
| 220ms | 1.000 | 0 | 主面板动画结束 |
| 240ms | 1.000 | 0 | 稳定，可用于终态断言 |

- 80ms 已接近终值、120ms 略过冲、220ms 归位，是这条 ease 的预期「弹性 pop」。
- 按钮在 0–24ms 内仍为 opacity 0；约 244ms 后终态；不要用 220ms 断言按钮已完全出现。

**关闭**

- 约 **140ms ease-in**：遮罩/面板/按钮 `opacity→0`；面板 `scale→0.97`；不做 translateY、不回弹。
- 关闭期间 `pointer-events:none`；140ms 后卸载 dialog、解除 body 锁定、焦点返回触发行。
- 若在打开动画中途关闭，直接从当前视觉状态走 140ms 关闭，不等待 220ms 回弹结束。

**reduced-motion**

- `prefers-reduced-motion: reduce`：移除 scale、translateY、回弹和所有 delay；opacity 用 0–1ms 直接切换（总时长 ≤1ms），等价于瞬时出现/消失。
- 滚动锁定、焦点进入/返回、背景 inert 仍即时生效；不等动画。
- 只动 `transform` / `opacity`：不改变面板宽高、内部列宽、按钮尺寸；不动画 `width/height/margin/filter/shadow`；面板 bbox 在动画全程固定。

### 9.2 滚动锁定

- 打开：记录 `scrollY`；`html, body { overflow: hidden; }`；按 `window.innerWidth - document.documentElement.clientWidth` 给 body 加 `padding-right` 补偿滚动条，避免页面横移。
- 关闭：恢复 overflow、padding 和滚动位置。
- 遮罩 `overscroll-behavior: none`；面板内简介/标签仍可滚，`data-preview-scroll` 容器滚到边界时吞掉滚轮。
- 页面在弹窗期间不滚动；V2 的「页面滚动关闭」逻辑移除。

### 9.3 DOM / 焦点

- 逻辑结构：`overlay(z100)` → `dialog-layer(z101, fixed inset 0, pointer-events:none, role=dialog, aria-modal=true)` → `panel(fixed, pointer-events:auto)` + `jump(fixed, pointer-events:auto)`；`hint(z102, pointer-events:none)` 在 dialog 层外。
- dialog 层覆盖视口但不接收指针事件，保证点遮罩空白仍命中遮罩；面板与按钮单独恢复 `pointer-events:auto`。
- 打开前记录 `document.activeElement`（触发行）。
- 打开后焦点移到 dialog 容器（`tabindex=-1`，无可见 outline）；背景容器设 `inert`（或等效焦点隔离）。
- Tab 顺序（按 DOM）：标签滚动区 → 简介滚动区 → BGM 按钮 → 回到标签（循环）。滚动区保留 V2 的 `tabIndex=0`。
- 关闭后焦点回触发行；若行已被移除，聚焦结果列表容器。
- 点击遮罩关闭后同样返回焦点。
- 右键关闭也要返回焦点（右键不应把焦点丢在 body）。

## 10. 可访问性

- 触发行有 `aria-haspopup="dialog"`；`role="dialog"`、`aria-modal="true"`、`aria-labelledby` 指向面板内标题（`id` 唯一）。
- `aria-describedby` 指向 sr-only 文案：「按 Esc 或右键任意处关闭」；视觉底部提示 `aria-hidden="true"`。
- 独立按钮是原生 `<a>`，有完整可访问名；可见「BGM」，`aria-label` 为「跳转至 BGM（在新标签页打开）」。
- 遮罩是装饰性 div，`aria-hidden="true"`；不设为可聚焦按钮，键盘关闭靠 Esc。
- 焦点圈：按钮/滚动区 `focus-visible` 可见（2px `#38BDF8`，offset 2）；dialog 容器无 outline。
- 对比：遮罩提示 `#334155` 对淡灰底 ≥4.5:1；按钮白字对 `#0F172A` ≥7:1；焦点环对深底可见。
- 不能只依赖右键关闭：Esc（建议）与遮罩点击（建议）必须至少确认一个，否则键盘/触屏用户无法关闭。
- 弹窗打开时背景 `inert`，屏幕阅读器不会读到列表；关闭后恢复。
