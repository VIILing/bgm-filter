# Round 4 · 条目预览改为「点击弹窗」

> 状态：需求已记录，等待 UI 设计稿经用户确认后再实现。
> 上游：`docs/round3-requirements.md`、`docs/ui-design.md` §2.12、`docs/round3-ui-spec.md`。
> 本文只描述「要什么」，不规定代码写法。

## 1. 背景与问题

Round 3 的预览是「鼠标悬浮条目 → 右侧固定面板」。实际使用中，鼠标从当前条目移向下一栏目时会扫过其他行，触发预览请求与面板切换，造成干扰。用户希望**换一种交互**：不再悬浮触发，改为**点击条目打开弹窗**。

## 2. 已确认的需求（来自用户）

1. **点击条目不再直接跳转 bgm.tv**，而是打开预览弹窗。
2. 弹窗内容**复用现有预览区域**（Round 3 V2：左原图封面 + 右标题/评分/标签，下方简介）；**预览区域内部布局不变**。
3. 预览区域在视口中**水平、垂直居中**。
4. 预览区域**右侧**有一个**独立的**「跳转至 BGM」按钮：
   - 不属于预览区域布局，不改变预览区域的内部结构；
   - 与预览区域有适当间距（不紧贴、不过远），水平高度上与预览区域一致；
   - 点击后跳转 bgm.tv；**点击该按钮不关闭弹窗**。
5. 弹窗出现时，预览区域外覆盖一层**淡灰色遮罩**（常见 dialog 效果）。
6. 弹窗期间，**右键点击任意位置即关闭弹窗**。
7. **取消悬浮预览**：鼠标划过条目不再加载/切换预览，避免误触。

## 3. 待确认的交互细节（设计稿中给建议，用户确认）

| 项 | 结论（2026-11-04 设计确认；2026-11-05 动效确认） |
| --- | --- |
| Esc 关闭 | **启用** |
| 左键点遮罩空白处关闭 | **启用**；点预览面板/跳转按钮不关闭 |
| 关闭提示 | **保留**，文案「点击空白处 / 右键 / Esc 关闭」 |
| 独立按钮样式 | **统一为 56×56 紧凑款**（不再使用 160×48 文字款） |
| 独立按钮位置 | **预览面板右侧、与面板顶部对齐（右上角外侧）**，不垂直居中；间距约 16–20px |
| 垂直居中 | **严格视口居中**；900 高时 top=40，接受面板压住 Header 底部约 16px |
| 设备/宽度 | **≥768 且鼠标设备启用**；触屏与 <768 点击仍直接跳 bgm.tv |
| 打开动画 | **弹性 pop（2026-11-05 用户确认）**：遮罩 opacity 180ms ease-out；面板 opacity 160ms + scale(0.92)/translateY(6px) → scale(1)/translateY(0)，220ms，`cubic-bezier(0.34,1.56,0.64,1)`；BGM 按钮延迟 20–30ms 跟随（约 244ms 完成）；关闭 140ms ease-in（scale→0.97）；reduced-motion 无缩放/位移/回弹，opacity ≤1ms |

> 以上为用户在 2026-11-04 设计确认时给出的最终选择；按钮统一 56×56、右上角外侧已按此更新。动效于 2026-11-05 追加确认为「弹性 pop」。

## 4. 交互规则

### 4.1 打开
- 点击条目卡片（封面/标题/信息区）→ 打开弹窗；同一时刻只允许一个。
- 点击行内**标签 chip** 仍执行原「追加筛选」行为，不打开弹窗。
- 悬浮仅保留行高亮，**不请求预览、不显示面板、不预取封面原图**。

### 4.2 弹窗期间
- 遮罩覆盖整个视口（含 Header），背景页面不滚动。
- 预览面板内部保持 Round 3 V2 的滚动行为（简介/标签内部滚，滚轮不带动页面）。
- 左键点击预览面板内容不关闭；点击右侧 BGM 按钮打开新标签页且**弹窗保持**。
- 右键点击任意位置（面板、按钮、遮罩）→ 关闭弹窗，并阻止浏览器右键菜单。
- Esc 关闭（建议）；左键点遮罩空白处关闭（建议，待确认）。
- 关闭后焦点回到触发条目；背景滚动恢复。

### 4.3 状态
- 打开瞬间显示预览面板的加载态（Round 3 的占位/骨架），数据到达后填充；不因加载改变面板几何。
- 无封面、原图失败、预览失败等降级与 Round 3 一致。
- 关闭时无残影；再次打开同一条目可正常显示。

## 5. 视觉与布局

- 预览区域沿用 Round 3 V2 尺寸：1440×900 下约 **880×820**；1024 宽 **848**；768 宽 **592**；内部结构、字号、间距不变。
- 居中：以视口中心定位（不是 Header 下方）。
- 独立按钮：统一 **56×56**，位于面板右缘外侧、**顶边与面板顶边平齐**；间距 20（1440/1280）/16（1024/768）；1024/768 下不超出视口。
- 遮罩：淡灰色半透明（设计给具体色值/透明度），面板保持白底、圆角、阴影层级高于遮罩。
- 视觉层级：遮罩 < 预览面板 < 独立按钮（按钮必须可点，不被遮罩挡住）。
- 1024/768 下预览面板与按钮的总宽不能溢出；如空间不足，优先缩小间距而不是压缩面板内部布局。

## 6. 非目标

- 不改预览面板内部布局、信息项、封面规则、简介滚动规则。
- 不改服务端接口、封面缓存、主数据库。
- 不做移动端专属交互（<768 暂沿用旧行为）。
- 不做多弹窗、拖拽、缩放、灯箱。

## 7. 资源与性能

- 预览数据与封面只在**点击后**加载；悬浮不再产生任何预览/原图请求。
- 相比 Round 3：误触请求减少；单次点击的资源开销与 Round 3 首次悬浮相同（原图 120–560 KB，暖缓存 0 请求）。
- 弹窗期间仅一张原图解码；无新增常驻内存。

## 8. 验收标准（设计确认后由 QA 独立执行）

1. 点击任意条目卡片 → 弹窗出现，预览区域在视口水平/垂直居中；内部布局与 Round 3 V2 一致（1440/1024/768 几何正确）。
2. 右侧独立 BGM 按钮：间距适当、垂直中心对齐、不溢出；点击打开 bgm.tv 且弹窗不关闭。
3. 遮罩为淡灰色、覆盖全屏；弹窗期间页面不滚动。
4. 右键任意位置关闭弹窗，浏览器右键菜单不出现；Esc（若确认）可关闭。
5. 悬浮条目不再出现预览、不再发预览/原图请求，仅行高亮。
6. 点击行内标签 chip 仍追加筛选，不打开弹窗。
7. 打开/关闭/切换条目无残影，加载态不改变面板几何；关闭后焦点回到条目。
8. 1024/768 下面板与按钮不溢出、不重叠；<768 行为符合确认结果。
9. 筛选、排序、分页、行内封面、URL 状态无回归。
10. `pnpm test` / `typecheck` / `build` / E2E 全绿；报告写入 `docs/qa-report-round4.md`。
